Пример 1: Интерактивные расширяющиеся панели (Accordion-галерея)
Краткое описание:
Этот пример демонстрирует создание горизонтального (по умолчанию) или вертикального (на мобильных) набора панелей с фоновыми изображениями. При клике на неактивную панель она плавно расширяется, занимая основное пространство, а остальные сжимаются.
Ключевые технологии и техники:
•	HTML: Простая структура с контейнером (.options) и элементами (.option).
•	CSS:
o	Flexbox: Активно используется для управления раскладкой и размерами панелей (display: flex, flex-grow, flex-basis).
o	CSS Переменные (:root): Для легкой настройки размеров, отступов, радиуса скругления и базового фона.
o	CSS Переходы (transition): Обеспечивают плавную анимацию расширения/сжатия панелей при изменении flex-grow.
o	Адаптивность (@media): Переключает flex-direction на column для узких экранов.
o	Фоновые изображения: background-image, background-size: cover, background-position: center.
o	Базовая поддержка темной темы: Через @media (prefers-color-scheme: dark).
•	JavaScript:
o	Минималистичный JS для обработки кликов.
o	Делегирование событий: Эффективно слушает клики на родительском контейнере (.options).
o	Динамически устанавливает CSS-переменную --total-options для корректной работы анимации flex-grow.
o	Переключает класс .active для управления состоянием панелей.
Дизайн и UX:
•	Визуальный эффект: Создает привлекательный и динамичный способ демонстрации изображений или контентных блоков.
•	Интерактивность: Простое и интуитивно понятное взаимодействие через клик.
•	Анимация: Плавная и приятная анимация перехода между состояниями.
Потенциальное использование (Идеи для вдохновения):
•	Галереи изображений (портфолио, фотоотчеты).
•	Представление различных опций или продуктов.
•	Интерактивное меню или навигация по разделам.
•	Визуализация шагов процесса или стадий.
•	Компактное отображение контента с возможностью "раскрытия" деталей.
Заметка: Отличный пример использования Flexbox для создания динамических, анимированных интерфейсов с минимальным JS. Хорошая основа для визуально насыщенных секций сайта.

Пример 2: Полноэкранный слайдер с синхронизированным видеофоном
Краткое описание:
Этот пример демонстрирует создание полноэкранного слайдера (карусели) с использованием библиотеки Swiper.js. Ключевая особенность — фоновое видео, воспроизведение которого синхронизировано со сменой слайдов с помощью анимационной библиотеки GSAP. Также присутствует стандартная верхняя навигационная панель.
Ключевые технологии и техники:
•	HTML: Структура включает верхнюю панель навигации (.top-line), контейнер для Swiper (.slider), слайды (.swiper-slide) с контентом, элементы управления Swiper (пагинация, кнопки навигации) и HTML5 video элемент для фона.
•	CSS:
o	CSS Переменные (:root): Используются для глобальных настроек (например, --index для адаптивных размеров) и кастомизации Swiper.
o	Flexbox: Применяется для центрирования контента внутри слайдов и для разметки навигационной панели.
o	Полноэкранный слайдер: Стилизация .slider для занятия всей высоты экрана (height: 100vh).
o	Адаптивные единицы (vw, vh, calc): Для гибкой типографики и отступов, реагирующих на размер вьюпорта.
o	Позиционирование: Фиксированное позиционирование (position: fixed) для видеофона и абсолютное (position: absolute) для верхней панели.
o	CSS Переходы (transition): Для плавного появления контента на активном слайде и изменения прозрачности видео.
•	JavaScript:
o	Swiper.js: Инициализация и конфигурация слайдера (скорость, управление мышью, пагинация, навигация).
o	GSAP (GreenSock Animation Platform): Используется для плавной анимации свойства currentTime видеоэлемента при смене слайдов (slideChange событие Swiper).
o	Управление видео: Синхронизация момента видео с активным слайдом.
o	Обработка событий Swiper: Использование slideChange, slideChangeTransitionStart, slideChangeTransitionEnd для управления анимацией видео и визуальными эффектами (например, изменением прозрачности видео во время перехода).
•	Зависимости: Требует подключения библиотек Swiper.js (CSS и JS) и GSAP.
•	Медиа: Использует фоновое видео (.mp4).
•	(Примечание): Проект также включает папки libs (для библиотек JS/CSS), img (для изображений, как логотип) и media (для видеофайла), которые не были включены в предоставленный код, но необходимы для полной функциональности.
Дизайн и UX:
•	Иммерсивный опыт: Полноэкранный формат и динамичный видеофон создают сильное визуальное впечатление.
•	Плавные переходы: Анимация смены слайдов и синхронизированное видео делают взаимодействие гладким.
•	Четкая навигация: Стандартные элементы управления Swiper (точки, стрелки) и верхнее меню.
•	Динамический контент: Текст на слайдах появляется плавно, привлекая внимание.
Потенциальное использование (Идеи для вдохновения):
•	Эффектные "hero sections" или главные экраны сайтов.
•	Презентация продуктов или услуг с визуальным акцентом.
•	Создание сайтов с повествованием (storytelling), где каждый слайд — это часть истории.
•	Портфолио с крупными визуальными элементами.
•	Промо-страницы для событий или кампаний.
Заметка: Этот пример хорошо демонстрирует интеграцию популярных JS-библиотек (Swiper, GSAP) для создания сложных и визуально насыщенных интерфейсов. Синхронизация видео и слайдера — продвинутая техника, которая может значительно усилить впечатление от сайта. Требует внимания к производительности из-за использования видео и анимаций.




Пример 3: Сайт с 3D-эффектом прокрутки
Краткое описание:
Этот пример демонстрирует создание веб-страницы с иммерсивным эффектом прокрутки, где контентные блоки (фреймы с текстом, изображениями и видео) перемещаются в трехмерном пространстве (по оси Z) при скролле пользователя. Создается иллюзия движения сквозь "туннель" контента. Также включает фоновую музыку с кнопкой управления.
Ключевые технологии и техники:
•	HTML: Использует контейнер с установленной CSS перспективой (.container), обертку галереи с transform-style: preserve-3d (.gallery), и набор полноэкранных "фреймов" (.frame), которые позиционируются абсолютно и перемещаются в 3D. Фреймы содержат контент (.frame__content), включая медиа-элементы (.frame-media, <video>). Есть элементы управления звуком (.soundbutton, .audio).
•	CSS:
o	CSS 3D Трансформации: Основа эффекта. Используются perspective, transform-style: preserve-3d, и динамически изменяемый transform: translateZ(...) для фреймов.
o	CSS Переменные (:root): Широко применяются для управления параметрами 3D-пространства (--depth, zSpacing в JS), размерами элементов (--index, --side-small, --side-big), отступами (--gutter) и скоростью анимации (--transition).
o	Позиционирование и Layout: Абсолютное позиционирование фреймов, Flexbox для центрирования контента внутри.
o	Плавные переходы (transition): Определены для transform и opacity, обеспечивая гладкость анимации при изменении стилей через JS.
o	Управление видимостью: Свойство opacity фреймов изменяется в JS в зависимости от их Z-позиции, создавая эффект появления/исчезновения.
o	Скрытие скроллбара: Применены стандартные CSS-правила для скрытия системного скроллбара.
o	Кастомные шрифты: Подключены через @font-face.
•	JavaScript:
o	Обработчик onscroll: Отслеживает позицию скролла (scrollTop).
o	Расчет 3D Позиций: Динамически вычисляет и обновляет translateZ для каждого фрейма на основе изменения позиции скролла (delta).
o	Манипуляция стилями: Напрямую изменяет style атрибут фреймов, устанавливая transform и opacity.
o	Управление аудио: Логика для кнопки включения/выключения звука и автоматической паузы/воспроизведения при смене фокуса окна браузера (onfocus, onblur).
•	Медиа: Использует фоновые изображения, видео (autoplay loop muted) и фоновый звук (.mp3).
•	(Примечание): Требуются соответствующие медиа-файлы (изображения, видео, аудио) и шрифты для полноценной работы.
Дизайн и UX:
•	Иммерсивность: Создает сильное ощущение глубины и погружения благодаря 3D-эффекту.
•	Динамика: Прокрутка становится активным элементом взаимодействия, управляющим анимацией.
•	Линейное повествование: Хорошо подходит для последовательного представления информации или истории.
•	Атмосфера: Фоновая музыка и визуальные эффекты способствуют созданию определенного настроения.
Потенциальное использование (Идеи для вдохновения):
•	Промо-сайты с акцентом на визуальное повествование.
•	Портфолио (особенно для фотографов, видеографов, дизайнеров).
•	Лендинги для представления продукта или услуги с "вау-эффектом".
•	Образовательные или информационные сайты, где каждый "фрейм" раскрывает новую тему.
•	Художественные или экспериментальные веб-проекты.
Заметка: Мощный визуальный эффект, но требует тщательной оптимизации производительности, так как постоянные вычисления и манипуляции DOM в onscroll могут быть ресурсоемкими, особенно на слабых устройствах. Использование will-change — шаг в правильном направлении. Необходимо тестировать на разных устройствах.



Пример 4: Креативный скролл-сайт с параллакс-эффектами (GSAP)
Краткое описание:
Этот пример демонстрирует создание веб-страницы с эффектом "творческой прокрутки", используя библиотеку GSAP и её плагины ScrollTrigger и ScrollSmoother. Основные особенности: плавный скролл, параллакс-эффект для фонового изображения в "hero" секции, а также для двух колонок галереи, которые движутся с разной скоростью при прокрутке. Элементы внутри колонок также анимированно появляются при скролле.
Ключевые технологии и техники:
•	HTML: Структура включает обертки .wrapper и .content (необходимые для ScrollSmoother), секцию героя (.hero-section) с фоновым изображением и заголовком, и секцию портфолио (.portfolio) с двухколоночной галереей (.gallery, .gallery__left, .gallery__right). Элементы, участвующие в параллаксе, имеют атрибут data-speed.
•	CSS:
o	CSS Переменные (:root): Используются для адаптивных размеров (--index), цветов и отступов (--gallery-gap).
o	Flexbox: Применяется для создания двухколоночного макета галереи.
o	Позиционирование: Абсолютное позиционирование для hero изображения.
o	Пользовательские шрифты: Подключены через @font-face.
o	Оптимизация will-change: Добавлено к элементам, которые активно анимируются (content, hero, main-header, gallery > *), для повышения производительности анимации.
o	Фоновое изображение: Установлено для body.
•	JavaScript (GSAP Suite):
o	GSAP (GreenSock Animation Platform): Ядро для всех анимаций.
o	ScrollTrigger: Плагин GSAP для запуска анимаций на основе позиции прокрутки. Используется для анимации появления элементов галереи (scrub: true для плавной привязки к скроллу) и для управления прозрачностью hero-section.
o	ScrollSmoother: Плагин GSAP для создания эффекта плавной прокрутки и для автоматического применения параллакс-эффекта к элементам с атрибутом data-speed (разные значения data-speed заставляют элементы двигаться с разной скоростью относительно скролла).
o	Анимации появления: Элементы галереи (.gallery__item) плавно появляются (изменяется opacity и x координата) при попадании в область видимости.
o	Условная инициализация: Эффекты ScrollSmoother и связанные анимации применяются только если устройство не является сенсорным (ScrollTrigger.isTouch !== 1), для лучшей производительности и UX на мобильных устройствах.
•	Зависимости: Требует подключения библиотек gsap.min.js, ScrollTrigger.min.js, ScrollSmoother.min.js.
•	Медиа: Использует изображения для фона, героя и галереи.
Дизайн и UX:
•	Плавность и динамика: ScrollSmoother и анимации GSAP создают очень плавный и отзывчивый опыт прокрутки.
•	Визуальная глубина: Параллакс-эффект на разных элементах (фон героя, колонки галереи) добавляет глубину и делает просмотр более увлекательным.
•	Привлечение внимания: Анимации появления контента направляют взгляд пользователя и делают интерфейс живым.
•	Структура "колонн": Разделение контента на две колонки с разной скоростью прокрутки — интересный визуальный прием.
Потенциальное использование (Идеи для вдохновения):
•	Сайты-портфолио (для дизайнеров, агентств, фотографов).
•	Промо-сайты или лендинги с акцентом на визуальную составляющую.
•	Представление продуктов или проектов, где важна эстетика.
•	Сайты с длинным контентом, который нужно сделать более увлекательным для прокрутки.
Заметка: Отличный пример использования GSAP для создания сложных, но плавных скролл-эффектов. Демонстрирует мощь ScrollSmoother для параллакса и ScrollTrigger для анимаций, управляемых прокруткой. Важно учитывать условное отключение эффектов для сенсорных устройств.




Пример 5: CSS Masonry-раскладка (Pinterest-стиль)
Краткое описание:
Этот пример демонстрирует создание "Masonry" (каменная кладка) раскладки для сетки элементов, подобной той, что используется на Pinterest, исключительно с помощью CSS. Элементы разной высоты располагаются в колонках, оптимально заполняя доступное пространство без использования JavaScript.
Ключевые технологии и техники:
•	HTML: Очень простая структура: контейнер (.list) и дочерние элементы (.item), содержащие изображения (<img>).
•	CSS:
o	CSS Multi-column Layout (columns): Основная техника. Свойство columns: 300px; (или другое значение ширины) указывает браузеру автоматически разбить содержимое контейнера .list на колонки указанной ширины. Количество колонок адаптируется под ширину контейнера.
o	column-gap: Устанавливает расстояние между колонками.
o	margin-bottom на .item: Создает вертикальный отступ между элементами в одной колонке.
o	Базовая стилизация изображений: width: 100% и display: block для корректного отображения изображений внутри .item.
o	CSS Переменные (:root): Используются для определения отступов (--gap).
•	JavaScript: Не используется. Решение полностью на CSS.
•	Зависимости: Только файлы изображений.
Дизайн и UX:
•	Визуальный эффект "Masonry": Эффективно располагает элементы разной высоты, минимизируя пустое пространство, что характерно для галерей в стиле Pinterest.
•	Адаптивность: Раскладка автоматически адаптируется к разной ширине экрана, изменяя количество колонок.
•	Простота: Очень легкое и производительное решение для данного типа раскладки.
Потенциальное использование (Идеи для вдохновения):
•	Фотогалереи.
•	Отображение портфолио или коллекций работ.
•	Ленты новостей или блогов с карточками разной высоты.
•	Доски настроения (mood boards).
•	Отображение продуктов в интернет-магазинах.
Преимущества и Ограничения:
•	Преимущества: Простота реализации, высокая производительность, не требует JS.
•	Ограничения: Порядок элементов идет сверху вниз в первой колонке, затем сверху вниз во второй и т.д. Это отличается от некоторых JS-библиотек Masonry, которые заполняют сетку по рядам, сохраняя более строгий горизонтальный порядок. Меньше контроля над точным позиционированием по сравнению с JS-решениями.
Заметка о взаимодополняемости: Этот пример показывает базовый, но эффективный CSS-подход к Masonry. Его можно рассматривать как альтернативу или отправную точку перед использованием более сложных JS-библиотек (если потребуется более точный контроль над порядком или анимациями). Может быть легко интегрирован в структуру страниц из других примеров.



Пример 6: Список с "плавающим" изображением-превью при наведении
Краткое описание:
Этот пример демонстрирует создание интерактивного списка (или меню), где при наведении курсора на пункт списка появляется изображение, связанное с этим пунктом, и следует за движением мыши, работая как кастомный "курсор". Дополнительно, при наведении слегка анимируется текст пункта и появляется полупрозрачный фоновый слой с тем же изображением.
Ключевые технологии и техники:
•	HTML: Структура состоит из контейнера (.magic-list) и элементов списка (.magic-list__item, реализованы как ссылки <a>). Каждый элемент содержит видимый заголовок (.magic-list__header), скрытый контейнер для "плавающего" изображения (.cursor > .cursor__image) и скрытый фоновый слой (.item-bg). Изображения задаются через инлайновый style="background-image: url(...)".
•	CSS:
o	CSS Переменные (:root, --move-x, --move-y): Ключевая техника. JavaScript обновляет --move-x и --move-y, а CSS использует их для позиционирования элемента .cursor через transform: translate3d(var(--move-x), var(--move-y), 0). Переменные также используются для настройки цветов (с функцией light-dark() для темной/светлой темы), размеров (--index) и скоростей анимации (--transition, --transition-cursor).
o	Позиционирование (position: fixed): Используется для .cursor и .item-bg, чтобы они могли перемещаться или отображаться независимо от потока документа.

Дизайн и UX:
•	Интерактивный предпросмотр: Дает пользователю визуальную подсказку о содержании пункта списка до клика.
•	Элегантная анимация: Плавные переходы и следование за курсором создают ощущение "магии" и высокого качества.
•	Уникальный курсор: Замена стандартного курсора на изображение при наведении на активные элементы.
•	Ненавязчивый фон: Легкий фоновый слой усиливает связь между пунктом и изображением, не перегружая интерфейс.
Потенциальное использование (Идеи для вдохновения):

•	Выбор категорий или продуктов с визуальным акцентом.
•	Интерактивные оглавления или выбор глав.
Заметка: Эффектный пример того, как с помощью минимального JS (только для получения координат) и мощных возможностей CSS (переменные, переходы, трансформации) можно создать сложную и привлекательную интерактивность. Пример 8: 3D Параллакс-сайт с эффектом "линзы" и дождем
Краткое описание:
Этот пример демонстрирует создание веб-страницы с многослойным 3D параллакс-эффектом, который реагирует на движение мыши, создавая иллюзию "линзы" или наклона сцены (tilt effect). Эффект достигается путем применения CSS 3D-трансформаций ко всей сцене на основе координат курсора. Дополнительно используется Canvas для анимации падающего дождя на одном из слоев.
Ключевые технологии и техники:
•	HTML:
o	Структура включает логотип (.logo), основную секцию (.layers), контейнер для слоев с 3D-свойствами (.layers__container), и сами слои (.layers__item).
o	Слои имеют фоновые изображения или контент (.hero-content с текстом и кнопкой).
o	Один из слоев содержит HTML5 canvas (.rain) для анимации дождя.
•	CSS:
o	CSS 3D Трансформации: Ключевая техника. perspective устанавливается на родительский контейнер (.layers). transform-style: preserve-3d применяется к .layers__container.
o	Размещение слоев в 3D: Каждый .layers__item позиционируется абсолютно (inset: -5vw для покрытия краев при наклоне) и смещается по оси Z с разным значением transform: translateZ(...) и scale(...), создавая глубину.
o	Эффект "линзы" (Tilt Effect): Контейнер .layers__container имеет transform: rotateX(var(--move-y)) rotateY(var(--move-x)). CSS переменные --move-x и --move-y динамически обновляются через JavaScript в зависимости от положения мыши.
o	CSS Переменные (:root, --move-x, --move-y): Используются для управления 3D-вращением и другими параметрами (например, --index).
o	Плавные переходы (transition): Применены к transform контейнера .layers__container для гладкой реакции на движение мыши.
o	Пользовательские шрифты: Загружены через @font-face.
o	Оптимизация will-change: Добавлена к .layers__container для улучшения производительности трансформаций.
o	pointer-events: none: Используется для верхних слоев (5, 6 и слой с дождем), чтобы они не мешали взаимодействию с контентом на нижних слоях.
•	JavaScript (app.js):
o	Отслеживание мыши: Слушает событие mousemove на документе.
o	Расчет углов наклона: Вычисляет небольшие углы поворота (--move-x, --move-y) на основе отклонения курсора от центра окна.
o	Обновление CSS переменных: Динамически устанавливает вычисленные значения CSS переменных на корневом элементе (documentElement), что приводит к обновлению transform в CSS.
•	JavaScript (libs/rain.js):
o	Canvas API: Используется для рисования 2D-графики (капель дождя).
o	Анимация: Создает массив объектов RainDrops, каждый со своей позицией, скоростью и прозрачностью.
o	Анимационный цикл (requestAnimationFrame): Постоянно перерисовывает холст, обновляя положение капель для создания эффекта непрерывного дождя.
•	Зависимости: Требуются файлы изображений (слои, логотип), шрифты и скрипт libs/rain.js.
Дизайн и UX:
•	Иммерсивность и глубина: 3D-слои и реакция на мышь создают сильное ощущение погружения и пространства.
•	Динамический фон: Эффект "линзы" делает статичную сцену живой и интерактивной.
•	Атмосферность: Анимация дождя усиливает общее настроение сцены (в данном случае, лесной пейзаж).
•	Фокус на контенте: Несмотря на сложный фон, основной контент (заголовок, текст, кнопка) остается в центре внимания на одном из слоев.
Потенциальное использование (Идеи для вдохновения):
•	Впечатляющие "hero sections" для сайтов.
•	Промо-страницы для игр, фильмов или событий.
•	Портфолио, где важна атмосфера и визуальный эффект.
•	Любые проекты, стремящиеся создать уникальный, запоминающийся визуальный опыт.
Заметка: Этот пример отлично сочетает мощь CSS 3D-трансформаций с динамическим обновлением через JavaScript для создания интерактивного параллакс-эффекта. Добавление Canvas-анимации показывает, как можно интегрировать разные технологии для обогащения визуального ряда. Важно тестировать производительность, особенно на мобильных устройствах, из-за сложности 3D-сцены и Canvas-анимации.





Пример 9: Параллакс-сайт с прокруткой (GSAP Smoother + CSS-переменная)
Краткое описание:
Этот пример демонстрирует создание веб-страницы с классическим многослойным параллакс-эффектом при прокрутке. Разные слои (фоновые изображения и текстовый заголовок) движутся с разной скоростью относительно скролла. Плавность прокрутки обеспечивается GSAP ScrollSmoother, а сам параллакс-эффект реализуется через CSS-трансформации, управляемые CSS-переменной (--scrollTop), которая обновляется с помощью JavaScript при скролле.
Ключевые технологии и техники:
•	HTML:
o	Структура включает обертки .wrapper и .content для GSAP ScrollSmoother.
o	Основной заголовок (.main-header) содержит контейнер слоев (.layers).
o	Слои (.layer) представлены div'ами с фоновыми изображениями (layers__base, layers__middle, layers__front).
o	Текстовый слой заголовка (.layer__header) также участвует в параллаксе.
o	Секция статьи (.main-article) следует за заголовком.
•	CSS:
o	CSS Переменные (:root, --scrollTop): --scrollTop является ключевой переменной, динамически обновляемой JS. Она используется в calc() для управления transform: translate3d слоев.
o	CSS 3D Трансформации (transform: translate3d): Основной механизм параллакса. Каждый слой имеет разный делитель для var(--scrollTop) (например, calc(var(--scrollTop) / 1.6)), что заставляет их двигаться с разной скоростью по вертикали при прокрутке.
o	Псевдо-элементы (::after): Используется на .main-header::after для создания эффекта "земли" или плавного визуального перехода между секцией заголовка и статьей.
o	Позиционирование и z-index: Абсолютное позиционирование слоев внутри .layers. z-index используется для правильного порядка слоев и для того, чтобы .main-article (с z-index: 10 и top: -1px) перекрывал псевдо-элемент "земли".
o	Пользовательские шрифты: Загружены через @font-face.
o	Оптимизация will-change: transform: Применена к анимируемым слоям и контенту для улучшения производительности.
o	CSS Переходы (transition): Установлены для transform, хотя основной эффект привязан к скроллу (плавность больше зависит от ScrollSmoother и частоты обновления --scrollTop).
•	JavaScript:
o	Обработчик события scroll: Слушает скролл окна и обновляет CSS-переменную --scrollTop на documentElement текущим значением window.scrollY. Это связывает позицию скролла с CSS-анимацией.
o	GSAP (ScrollTrigger, ScrollSmoother): Используются для создания эффекта плавной прокрутки (ScrollSmoother.create). ScrollTrigger регистрируется, но в данном коде не используется для явных анимаций параллакса (они управляются через CSS переменную).
•	Зависимости: GSAP (Core, ScrollTrigger, ScrollSmoother), шрифты, изображения для слоев и фона.
Дизайн и UX:
•	Классический параллакс: Создает ощущение глубины и динамики при прокрутке страницы.
•	Плавный скролл: GSAP ScrollSmoother обеспечивает приятный и плавный опыт прокрутки.
•	Визуальная глубина: Разная скорость движения слоев усиливает иллюзию трехмерного пространства.
•	Бесшовный переход: Элемент "земли" (main-header::after) создает красивый переход между секциями.
Потенциальное использование (Идеи для вдохновения):
•	"Hero sections" или главные экраны сайтов с сильным визуальным акцентом.
•	Лендинги, рассказывающие историю или представляющие продукт.
•	Сайты, где нужно создать атмосферу погружения (например, природа, космос, фэнтези).
Заметка: Этот пример иллюстрирует интересный подход, сочетающий ручное обновление CSS-переменной через JS для управления параллаксом в CSS и использование GSAP преимущественно для сглаживания прокрутки. Это может быть альтернативой полному управлению параллаксом через GSAP (как в Примере 4), потенциально давая браузеру больше контроля над оптимизацией рендеринга CSS-трансформаций.
